# Generic code page

Public static page with Copy and Select all buttons. Publish only this directory, never the surrounding workspace or application repository. No analytics, secrets, private configuration, remote scripts, uploads, or execution of displayed code.

Update snippet.json from home with generic code, a title, revision and instructions, then commit. Visitors refresh to see the latest version. GitHub Pages serves main / (root). Public readers do not sign in. This is not a synchronized editable textpad.
